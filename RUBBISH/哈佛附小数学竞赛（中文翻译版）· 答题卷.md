1. （代数）设$G$是⼀个阶为 12 的非交换群。证明： $G$的不可约复表示个数只能是$4$或$6$，并给出这两种情况都能出现的例⼦。
	
	由于$G$非交换，换位子群$G' \neq \{e\}$，1维表示个数$n_{1}=|\frac{G}{G'}| < 12$.
	又$n_{1} | 12$，故$n_{1} \in \{1, 2, 3, 4, 6\}$.
	设高维不可约表示的维数为$d_{i} \geq {2}$s，$12 = n_{1}+\sum_{i} d_{i}^2$
	* $n_{1} = 1, 2, 6$时，$\sum d_{i}^2$不能表示为大于等于2的整数平方和.
	* $n_{1} = 3$时，$\sum d_{i}^2 = 9 = 3^2$，总个数$3 + 1 = 4$.
	* $n_{1} = 4$时，$\sum d_{i}^2 = 8 = 2^2 + 2^2$，总个数$4 + 2 = 6$.
	
	例子：4个元素的偶置换群$A_{4}$，正六边形的对称群$D_{6}$.

2. （代数⼏何）
	$(a).$
		$R = \mathbb{C}[x] / {x^3-2x^2+x}$.
		$x^3-2x^2+x=x(x-1)^2$，在商环中$(x-1)^2=0$，但$x-1 \neq 0$，故该环不是既约环，不能作为仿射代数簇的坐标环.
		$R = \mathbb{C}[x] / (x^3-1)$
		$x^3-1 =  (x-1)(x-\omega)(x-\omega^2)$，其中$\omega= e^{2\pi i / 3}$为三次本原单位根，由中国剩余定理，$\mathbb{C}[x] / (x^3-1) \cong \mathbb{C} \times \mathbb{C} \times \mathbb{C}$，故该环可以作为仿射代数簇的坐标环.
	$(b).$
		$X = V(xy(x-y)) \subseteq \mathbb{A_{C}}^2$.
		由3条过原点的直线构成：$x=0, y=0, y=x$.
		$Y = V(xy,yz,xz) \subseteq \mathbb{A_{C}}^3$.
		由3个平面构成：$xy=0, yz=0, xz=0$，且至少两个坐标为0.
		对于$X$，定义方程$f=xy(x-y) = x^2y-xy^2$.
		$\frac{{\partial f}}{\partial x} = 2xy-y^2$，在原点处为0.
		$\frac{{\partial f}}{\partial y} = -2xy+x^2$，在原点处为0.
		在原点处的切空间维度$D_{X} = 2 - 0 = 2$
		对于$Y$，定义理想$I=(xy,yz,xz)$.
		易得所有生成元的偏导数在原点都为0，在原点处的切空间维度$D_{Y} = 3 - 0 = 3$
		由于$D_{x} \neq D_{Y}$，故$X \ncong Y$
